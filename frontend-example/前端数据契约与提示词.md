## 提示词（直接复制给 AI 工具）

```
请开发一个公积金政策查询 HTML 页面（单文件，样式需求见下方我的补充说明）。

【数据来源】
页面通过 fetch('./db.json?v=' + Date.now()) 加载数据（必须加 ?v= 时间戳防缓存）。
db.json 与 index.html 位于同一目录，无需任何后端、无任何鉴权。

【数据结构 TypeScript 定义】
interface Source { title: string; url: string; date: string }
interface Deposit {          // 缴存政策
  base_upper: number | null  // 缴存基数上限（元/月）
  base_lower: number | null  // 缴存基数下限（元/月）
  ratio: string | null       // 缴存比例，如 "5%-12%"
  period: string | null      // 执行年度
  note: string               // 备注（可能含来源性质说明）
  sources: Source[]
}
interface Withdrawal {       // 提取政策
  conditions: string[]       // 提取情形，如 ["购房","租房","退休",...]
  rent_limit: string | null  // 租房提取额度说明
  note: string
  sources: Source[]
}
interface Loan {             // 贷款政策
  max_single: string | null            // 单人最高额度
  max_family: string | null            // 家庭最高额度
  rate_first: string | null            // 首套利率
  rate_second: string | null           // 二套利率
  down_payment_first: string | null    // 首套首付比例
  down_payment_second: string | null   // 二套首付比例
  conditions: string | null            // 基本贷款条件
  note: string
  sources: Source[]
}
interface City {
  city: string                 // 城市名
  full_name?: string           // 完整行政区划名（少数城市有，如"红河州"）
  province: string
  last_updated: string         // 该城数据更新日期
  official_site: string | null // 市公积金中心官网
  deposit: Deposit
  withdrawal: Withdrawal
  loan: Loan
}
interface Database {
  database: string
  version: string              // 语义化版本，每次数据更新递增
  generated_at: string         // 数据库生成日期
  city_count: number           // 134
  cities: City[]
}

【渲染规则（必须遵守）】
1. 任何字段为 null 或空字符串时显示 "—"，不要留空白或显示 "null"。
2. note 字段非空时必须展示（内含重要的政策时效/口径说明）。
3. sources 数组渲染为可点击链接列表（target="_blank" rel="noopener"），
   格式：标题（日期），这是数据可信度的关键。
4. 页面头部展示数据版本号 version 和更新日期 generated_at，让用户知道数据新鲜度。
5. 数据量约 134 城市 × 3 类政策，需考虑列表性能（如按需渲染详情）。
```

## 对接不变量（无论样式怎么改，这些不要动）

| 项 | 约定 |
|---|---|
| 数据文件 | 同目录 `db.json` |
| 加载方式 | `fetch('./db.json?v=' + Date.now())` |
| 字段名 | 严格按上方 TypeScript 定义，数据库端保证 schema 稳定 |
| null 语义 | "未找到官方公开来源"，UI 显示 "—" |

- **页面开发好后发给我**：我可以帮你检查数据绑定是否正确、并直接接入仓库完成部署

```typescript
interface CaseItem {

  title: string

  parties: string[]          // 参与机构

  summary: string            // 案例概述

  sources: Source[]
```
